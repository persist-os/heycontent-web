# Persona Crystallization System - Frontend

## Overview

The Persona Crystallization System automatically extracts psychological insights from user conversations and crystallizes them into stable persona profiles. The frontend manages real-time processing orchestration, sophisticated error handling, and seamless integration with the Python backend via proxy APIs.

## Post-Refactoring Architecture

**Streamlined Data Flow:** User Message → Direct Backend Processing → Trace Storage → Auto-Crystallization → Real-time Persona Updates

**Key Principle:** Traces and insights persist indefinitely. Persona profiles are dynamically generated by combining all traces + insights for comprehensive psychological understanding.

**Architectural Improvement:** Removed deprecated Convex actions that created complexity. All processing now flows through authenticated frontend → backend API → Convex storage.

## System Intelligence and User Experience

### Auto-Crystallization Intelligence

**Smart Trigger Detection:** The system automatically detects when conversations contain sufficient psychological content for trace extraction, balancing processing efficiency with comprehensive analysis.

**Confidence-Driven Processing:** Auto-crystallization only triggers when trace confidence scores suggest meaningful insights can be derived, preventing noise accumulation.

**Resource-Aware Scheduling:** Processing is scheduled to avoid user-facing latency, with background crystallization occurring during natural conversation pauses.

### Advanced Error Recovery

**Multi-Layer Resilience:**

```typescript
interface PersonaError {
  type: 'network' | 'authentication' | 'validation' | 'backend' | 'unknown';
  message: string;
  retryable: boolean;
  retryCount?: number;
  context?: ProcessingContext;
}
```

**Intelligent Recovery Strategies:**

- **Contextual Retry Logic:** Different retry strategies for extraction vs crystallization failures
- **Graceful Degradation:** Partial processing results preserved when full pipeline fails
- **User Communication:** Transparent error messaging without exposing technical complexity
- **State Recovery:** Automatic state restoration after transient failures
